# Ancient Realms Workstations

Eight themed workstation blocks are registered: Dragon Forge, Rune Anvil, Soul Altar, Elemental Crucible, Celestial Loom, Blood Infuser, Eternal Foundry and World Core Matrix.

Each currently uses Minecraft's native crafting-table block interaction, providing a working 3x3 crafting screen and vanilla recipe execution. They have blockstates, block/item models, loot tables, translations and creative-tab entries. Custom station-specific menus, recipe filters, processing timers, upgrades and progression gates remain outstanding.
