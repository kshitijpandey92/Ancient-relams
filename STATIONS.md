# Ancient Realms Workstations

Eight themed workstations are registered: Dragon Forge, Rune Anvil, Soul Altar, Elemental Crucible, Celestial Loom, Blood Infuser, Eternal Foundry and World Core Matrix. They currently use Minecraft's native crafting-table block interaction, providing a working 3x3 crafting screen and vanilla recipe execution. Custom station-specific menus, recipe filters, processing timers, upgrades and progression gates are not implemented yet.
