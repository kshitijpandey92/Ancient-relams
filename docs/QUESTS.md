# Quest content

The project now contains an advancement-based dragon-hunt quest chain, visible in Minecraft's Advancements screen:

1. **The Ember Hunt** — defeat an Ember Dragon; awards 100 XP.
2. **A Cold Victory** — defeat a Frost Dragon after the Ember Hunt; awards 150 XP.
3. **Eye of the Storm** — defeat a Storm Dragon after the Frost Hunt; awards 250 XP.

Advancement progress is tracked by Minecraft and persists per player. These are real kill-triggered objectives, not placeholder command flags.
